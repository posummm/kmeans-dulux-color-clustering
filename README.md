# K-Means Dulux Color Clustering

Project clustering warna cat Dulux menggunakan algoritma K-Means dan metode Euclidean Distance berdasarkan nilai RGB.

## 📌 Deskripsi
Project ini bertujuan untuk:
- Mengelompokkan warna berdasarkan kemiripan RGB
- Menganalisis warna dominan pada gambar
- Memberikan rekomendasi warna Dulux yang paling mendekati

## 📌 Dataset
Dataset diambil dari katalog warna Dulux dan berisi:
- Nilai RGB
- Kode HEX
- Nama warna

Total dataset: 144 warna.

## 📌 Algoritma
- K-Means Clustering
- Euclidean Distance

## 📌 Features
- RGB Color Clustering
- 3D Visualization
- Image Testing
- Mean RGB Calculation
- Color Recommendation

## 📌 Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Google Colab

## 📌 Testing
Gambar testing diperkecil menjadi 3x3 pixel lalu dihitung mean RGB-nya untuk menentukan cluster warna yang paling sesuai.
